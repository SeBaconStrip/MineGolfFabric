# Golf Cart Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A drivable two-seat golf cart with a golf bag holder.

**Architecture:** Pure `CartPhysics` for speed and steering (unit tested). `GolfCartEntity` extends `VehicleEntity` and,
like a boat, is moved by the driver's client from the player's move input. A code-defined entity model and a generated
texture draw it.

**Tech Stack:** Fabric 26.3 (Mojang names), Fabric API 0.164.0, Java 25, JUnit 5, Fabric gametests.

**Spec:** `docs/superpowers/specs/2026-10-25-golf-cart-design.md`

## Global Constraints

- Build: `export JAVA_HOME="$(cygpath -w ~/.jdks/jdk-25.0.4.1+1)"`, then `./gradlew build` and `./gradlew runGametest`.
- `net.colin.minegolf.physics` must not import `net.minecraft.*`.
- Assets via `tools/gen_assets.py`; lang keys in `en_us.json`.

---

### Task 1: CartPhysics
- Files: `physics/CartPhysics.java`, test `physics/CartPhysicsTest.java`.
- Produces: `CartPhysics.State {double speed; float yaw;}`, `record Input(boolean forward, back, left, right)`,
  `static void step(State, Input)`, constants `MAX_SPEED`, `MAX_REVERSE`, `ACCELERATION`, `BRAKE`, `FRICTION`,
  `MAX_TURN`.
- [ ] Tests from the spec, then implement, `./gradlew test` green.

### Task 2: Entity, item, bag holder
- Files: `entity/GolfCartEntity.java`, `item/GolfCartItem.java`; modify `ModEntities`, `ModItems`, `GolfBagItem.cycleClub`.
- Entity: sized 1.4 × 1.0, `maxUpStep` 1.0, 2 passengers, attachment points ±0.32 lateral, ride height 0.45.
  - On the driving client: `CartPhysics.step` from `driver.zza` / `driver.xxa`, then `move(SELF)`.
  - Without a driver on the server: friction and gravity only.
  - `positionRider` turns passengers with the cart and clamps them like a boat.
- Interact: bag in hand → load; sneak + empty hand → unload; otherwise ride.
- `destroy` drops the bag too; `getDropItem` = golf cart item.
- [ ] Gametests: `cartItemPlacesCart`, `cartHoldsBagAndDropsItWhenBroken`, `clubKeyUsesCartBag`.

### Task 3: Model, renderer, texture, recipe
- Client: `GolfCartModel`, `GolfCartRenderState`, `GolfCartRenderer`; register in `MineGolfClient`.
- `gen_assets.py`: `textures/entity/golf_cart.png` (256×256 colour zones), item texture `golf_cart`, item model,
  recipe and unlock (`minecraft:minecart`). Recipe test expects 19.
- [ ] Lang: item and entity names. README, CHANGELOG, description, version 0.3.0.
- [ ] `./gradlew build runGametest` green; check in game; commit and push.
