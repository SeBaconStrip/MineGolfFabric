# MineGolf Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Playable v1 of MineGolf: clubs, balls, bag, turf, course building with a Course Book, solo and group rounds with HUD and scorecard.

**Architecture:** Pure-Java physics and scoring cores (unit tested with JUnit) wrapped by thin Minecraft glue: a server-authoritative `GolfBallEntity`, club items driven by vanilla item-use charging (`use` → `releaseUsing` runs on the server, so no shot packet is needed), a server-wide `CourseSavedData`, an in-memory `RoundManager`, and Fabric payloads for screens and HUD state.

**Tech Stack:** Fabric Loom 1.18-SNAPSHOT, Minecraft 26.3 (Mojang names), Fabric loader 0.19.5, Fabric API 0.164.0+26.3, Java 25, JUnit 5.11.4, Fabric gametest.

**Spec:** `docs/superpowers/specs/2026-10-19-minegolf-design.md`

## Global Constraints

- Mod id `minegolf`, package `net.colin.minegolf`, client code in `src/client/java` (split source sets).
- Build with `JAVA_HOME` = `~/.jdks/jdk-25.0.4.1+1` (system JDK is 21).
- Units: blocks and ticks. Gravity 0.05, air drag 0.99, rest threshold 0.005 for 10 ticks.
- `net.colin.minegolf.physics` and `round.Scorecard` must not import `net.minecraft.*`.
- Server validates everything; clients only render and send intents.
- No wind, records, golf cart, slopes, spin, persistent rounds (spec "Out of scope").

### Task 1: Physics core

**Files:** Create `physics/Surface.java`, `SurfaceLookup.java`, `BallState.java`, `BallPhysics.java`, `Club.java`; Test `src/test/java/net/colin/minegolf/physics/BallPhysicsTest.java`

**Interfaces — Produces:**
- `enum Surface { GREEN(0.20, 0.985, 0.70, 1.0), FAIRWAY(0.35, 0.92, 0.75, 1.0), ROUGH(0.15, 0.80, 0.50, 0.75), BUNKER(0.0, 0.60, 0.10, 0.40), ICE(0.30, 0.995, 0.95, 1.0) }`
  with fields `restitution, rollFriction, impactKeep, lieModifier`.
- `interface SurfaceLookup { double height(int x,int y,int z); Surface surface(int x,int y,int z); boolean hazard(int x,int y,int z); boolean isCup(int x,int y,int z); int minY(); }`
  `height` = collision top of the block in [0,1], 0 = passable.
- `enum Club { DRIVER(3.48, 12), IRON(2.03, 25), WEDGE(1.28, 50), PUTTER(0.23, 0) }` with `maxSpeed()`, `launchDegrees()`.
- `final class BallState { double x,y,z,vx,vy,vz; boolean onGround; int restTicks; int ticksMoving; boolean resting(); }`
- `BallPhysics.launch(BallState s, Club club, double power, float yawDegrees, Surface lie)` — sets velocity
  (`speed = maxSpeed * clamp(power) * (club == WEDGE && lie == BUNKER ? 1 : lie.lieModifier)`,
  direction `(-sin yaw, cos yaw)`), clears rest/ground.
- `BallPhysics.Event step(BallState s, SurfaceLookup w)` with `enum Event { NONE, LANDED, AT_REST, HOLED, HAZARD, STUCK }`.

Algorithm (point ball, position = bottom center, STEP = 0.15, sub-steps ≤ 0.4 blocks):
air → `vy -= 0.05; v *= 0.99`; ground → `vy = 0; vx,vz *= surface.rollFriction`.
Horizontal move per axis: `top(nx, y, nz) > y + STEP` → wall, reflect axis × −0.5.
Falling onto `top ≥ newY` → land at top, `vy = -vy * restitution`, horizontal × `impactKeep`, `vy < 0.08` → ground.
Rolling off an edge → airborne. Rolling onto `top ∈ (y, y+STEP]` → step up.
Cup: ball on a cup block, horizontal distance to center ≤ 0.3, horizontal speed < 0.35 → HOLED.
Hazard: `hazard(x, floor y, z)` or `y < minY` → HAZARD. Rest: speed < 0.005 on ground for 10 ticks → AT_REST.
Stuck: `ticksMoving > 600` → STUCK.

```java
package net.colin.minegolf.physics;

import org.junit.jupiter.api.Test;
import static org.junit.jupiter.api.Assertions.*;

class BallPhysicsTest {
    /** Flat world: ground block top at y=0 of the given surface, optional cup and water columns. */
    static SurfaceLookup flat(Surface s, int cupX, int cupZ, int waterX) {
        return new SurfaceLookup() {
            public double height(int x, int y, int z) { return y == -1 ? 1.0 : (y < -1 ? 1.0 : 0.0); }
            public Surface surface(int x, int y, int z) { return s; }
            public boolean hazard(int x, int y, int z) { return x == waterX && y == 0; }
            public boolean isCup(int x, int y, int z) { return x == cupX && z == cupZ && y == -1; }
            public int minY() { return -64; }
        };
    }

    static BallState ballAt(double x, double z) {
        BallState s = new BallState();
        s.x = x; s.y = 0; s.z = z; s.onGround = true;
        return s;
    }

    static BallPhysics.Event runUntilDone(BallState s, SurfaceLookup w) {
        for (int i = 0; i < 2000; i++) {
            BallPhysics.Event e = BallPhysics.step(s, w);
            if (e != BallPhysics.Event.NONE && e != BallPhysics.Event.LANDED) return e;
        }
        return BallPhysics.Event.NONE;
    }

    static double carry(Club club, Surface ground) {
        BallState s = ballAt(0.5, 0.5);
        BallPhysics.launch(s, club, 1.0, 0f, Surface.FAIRWAY);
        SurfaceLookup w = flat(ground, 9999, 9999, 9999);
        for (int i = 0; i < 400; i++) {
            if (BallPhysics.step(s, w) == BallPhysics.Event.LANDED) return s.z - 0.5;
        }
        return -1;
    }

    @Test void driverCarriesAbout80() { assertEquals(80, carry(Club.DRIVER, Surface.FAIRWAY), 12); }
    @Test void ironCarriesAbout50() { assertEquals(50, carry(Club.IRON, Surface.FAIRWAY), 7.5); }
    @Test void wedgeCarriesAbout25() { assertEquals(25, carry(Club.WEDGE, Surface.FAIRWAY), 4); }

    @Test void putterRollsAbout15OnGreen() {
        BallState s = ballAt(0.5, 0.5);
        BallPhysics.launch(s, Club.PUTTER, 1.0, 0f, Surface.GREEN);
        assertEquals(BallPhysics.Event.AT_REST, runUntilDone(s, flat(Surface.GREEN, 9999, 9999, 9999)));
        assertEquals(15, s.z - 0.5, 2.5);
        assertTrue(s.resting());
    }

    @Test void bunkerPlugsBall() {
        BallState s = ballAt(0.5, 0.5);
        BallPhysics.launch(s, Club.IRON, 1.0, 0f, Surface.FAIRWAY);
        SurfaceLookup w = flat(Surface.BUNKER, 9999, 9999, 9999);
        double landedAt = -1;
        for (int i = 0; i < 400 && landedAt < 0; i++) if (BallPhysics.step(s, w) == BallPhysics.Event.LANDED) landedAt = s.z;
        assertEquals(BallPhysics.Event.AT_REST, runUntilDone(s, w));
        assertTrue(s.z - landedAt < 3, "ball should stop within 3 blocks of landing in a bunker");
    }

    @Test void slowPuttDropsIntoCup() {
        BallState s = ballAt(0.5, 0.5);
        BallPhysics.launch(s, Club.PUTTER, 0.35, 0f, Surface.GREEN); // ~5 blocks
        assertEquals(BallPhysics.Event.HOLED, runUntilDone(s, flat(Surface.GREEN, 0, 3, 9999)));
    }

    @Test void fastBallLipsOut() {
        BallState s = ballAt(0.5, 0.5);
        s.vz = 0.6; s.onGround = true; // too fast for the cup at z=2
        BallPhysics.Event e = runUntilDone(s, flat(Surface.ICE, 0, 2, 9999));
        assertNotEquals(BallPhysics.Event.HOLED, e);
    }

    @Test void waterIsHazard() {
        BallState s = ballAt(0.5, 0.5);
        s.vx = 0.3; s.onGround = true;
        assertEquals(BallPhysics.Event.HAZARD, runUntilDone(s, flat(Surface.ICE, 9999, 9999, 3)));
    }

    @Test void wallReflectsWithoutTunneling() {
        SurfaceLookup wall = new SurfaceLookup() {
            public double height(int x, int y, int z) { return y < 0 || (z == 5 && y < 3) ? 1.0 : 0.0; }
            public Surface surface(int x, int y, int z) { return Surface.GREEN; }
            public boolean hazard(int x, int y, int z) { return false; }
            public boolean isCup(int x, int y, int z) { return false; }
            public int minY() { return -64; }
        };
        BallState s = ballAt(0.5, 0.5);
        s.vz = 3.0; s.onGround = true;
        runUntilDone(s, wall);
        assertTrue(s.z < 5, "ball must stay in front of the wall, was " + s.z);
    }

    @Test void stepsUpOntoCarpetHeightBlocks() {
        SurfaceLookup mat = new SurfaceLookup() {
            public double height(int x, int y, int z) { return y < 0 ? 1.0 : (y == 0 && z >= 3 ? 0.0625 : 0.0); }
            public Surface surface(int x, int y, int z) { return Surface.GREEN; }
            public boolean hazard(int x, int y, int z) { return false; }
            public boolean isCup(int x, int y, int z) { return false; }
            public int minY() { return -64; }
        };
        BallState s = ballAt(0.5, 0.5);
        s.vz = 0.2; s.onGround = true;
        runUntilDone(s, mat);
        assertTrue(s.z > 4, "ball should roll over the mat");
        assertEquals(0.0625, s.y, 1e-6);
    }
}
```

package net.colin.minegolf.round;

import org.junit.jupiter.api.Test;
import java.util.UUID;
import static org.junit.jupiter.api.Assertions.*;

class ScorecardTest {
    final UUID a = UUID.randomUUID(), b = UUID.randomUUID();

    @Test void totalsAndRelativeToPar() {
        Scorecard c = new Scorecard(new int[]{3, 4});
        c.addPlayer(a, "A");
        for (int i = 0; i < 4; i++) c.addStroke(a, 0);
        c.finishHole(a, 0);
        for (int i = 0; i < 3; i++) c.addStroke(a, 1);
        c.finishHole(a, 1);
        assertEquals(7, c.total(a));
        assertEquals(0, c.relativeToPar(a));
    }

    @Test void pickupScoresDoublePar() {
        Scorecard c = new Scorecard(new int[]{3});
        c.addPlayer(a, "A");
        c.addStroke(a, 0);
        c.pickup(a, 0);
        assertEquals(6, c.strokes(a, 0));
        assertTrue(c.isFinished(a, 0));
    }

    @Test void capReachedAtDoublePar() {
        Scorecard c = new Scorecard(new int[]{2});
        c.addPlayer(a, "A");
        for (int i = 0; i < 3; i++) c.addStroke(a, 0);
        assertFalse(c.reachedCap(a, 0));
        c.addStroke(a, 0);
        assertTrue(c.reachedCap(a, 0));
    }

    @Test void holeCompleteOnlyWhenEveryoneFinished() {
        Scorecard c = new Scorecard(new int[]{3});
        c.addPlayer(a, "A");
        c.addPlayer(b, "B");
        c.addStroke(a, 0);
        c.finishHole(a, 0);
        assertFalse(c.holeComplete(0));
        c.pickup(b, 0);
        assertTrue(c.holeComplete(0));
    }

    @Test void removedPlayerNoLongerBlocksHole() {
        Scorecard c = new Scorecard(new int[]{3});
        c.addPlayer(a, "A");
        c.addPlayer(b, "B");
        c.finishHole(a, 0);
        c.removePlayer(b);
        assertTrue(c.holeComplete(0));
    }
}

### Task 5: Club shot, power bar, aim line

**Files:** `item/ClubItem`, client `GolfHud`, `AimLine`.

`ClubItem(Club club)`: `use` → server finds own resting ball within 2.5 blocks (`GolfBallEntity.findOwnBall`); if none
→ action bar `minegolf.msg.no_ball`, `FAIL`; driver off tee → `minegolf.msg.driver_tee_only`; else `startUsingItem`,
`CONSUME`. Client side returns `CONSUME` when a nearby own ball exists (client entity list check) to start the animation.
`getUseDuration` 72000, animation `NONE`.
`releaseUsing`: ticks = 72000 − remaining; `power = Shot.power(ticks)` (ticks ≤ 30 → t/30; ≤ 60 → 1; else 0);
server: ball.hit(club, power, player.getYRot()) → +1 stroke via RoundManager. Return true.
`Shot.power(int)` lives in `physics/Club.java` as static `powerForTicks` (pure, unit-tested: 0→0, 15→0.5, 30→1, 59→1, 61→0).
HUD power bar: when local player `isUsingItem()` with a ClubItem, draw 102×7 bar centered above hotbar.
Aim line: client tick, while charging, copy `BallState` from ball entity, `launch` with current power, step 30 ticks
using a client `LevelSurfaceLookup`, spawn `ParticleTypes.END_ROD`-like dust every 2nd point (`level.addParticle`).
